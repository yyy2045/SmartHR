项目名称：SmartHR - 多智能体协作招聘平台
一、项目简介
SmartHR 是一款面向企业 HR 和面试官的智能招聘辅助系统。它区别于传统的简历解析工具，采用多智能体协作架构，模拟真实招聘委员会的工作模式，为候选人评估和面试决策提供多维度的智能支持。系统通过 Java 与 Python 双语言协同，在保证业务逻辑稳定性的同时，注入强大的 AI 推理能力，实现了从简历筛选到面试评估的全流程智能化。

二、核心业务功能
简历智能匹配与解析

HR 发布岗位并上传批量简历后，系统利用 RAG (检索增强生成) 技术，结合向量数据库对岗位 JD 与简历进行语义匹配，自动生成人岗匹配度打分报告。

多智能体协作面试

这是系统核心亮点。一场面试由一个虚拟面试委员会完成，包含多个基于 LangGraph 构建的专家智能体：

主面试官智能体：主导提问流程，根据岗位要求从题库抽题或动态生成问题，与候选人交互。

技能评估智能体：专门负责评估候选人回答中的技术深度、准确性，并调用检索工具核验事实。

行为分析智能体：分析沟通中的软素质、逻辑性与团队协作倾向。

报告生成智能体：交叉验证各智能体的评估结论，生成带加权评分与录用建议的结构化报告。

多个智能体在 LangGraph 状态图中有序并行工作，模拟真实面试中的多角色决策。

智能上下文记忆与连续性

所有智能体都是无状态的，它们的“记忆”统一存储在 Redis 中。包括面试对话历史、当前岗位上下文和 HR 的筛选偏好。

作用：即使面试官中途断线，只要会话未过期，就能从上次断点继续；HR 连续操作时，系统能记住其偏好并主动适配。

企业动态知识库

支持上传公司制度、技术规范等文档，构建专属知识库。面试过程中，智能体可以从知识库检索相关制度，辅助生成更符合企业实际的提问或评估标准。

三、技术架构与协作流程
整体采用 前后端分离 + AI 微服务 架构：

text
[前端 Vue/React] 
    |
[Java 主业务层 (Spring Boot)]  —— [MySQL] (用户、岗位、简历等业务数据)
    |                        —— [Redis] (会话记忆、高频缓存、上下文状态)
    |
[Python AI 服务层 (FastAPI)]    —— [向量数据库] (简历与 JD 语义向量)
    |                        —— [LangChain + LangGraph] (RAG流程、多智能体编排)
    |
[LLM 大模型 API]
Java 层 负责：认证授权 (JWT)、业务 REST API、会话管理、结果持久化。

Python 层 负责：所有 AI 推理任务（简历解析、RAG 检索、多智能体协作流程），通过 FastAPI 暴露接口供 Java 调用。

Redis 作为两层之间的共享记忆中枢，承载智能体对话历史和用户偏好上下文。

向量数据库 存储文本嵌入向量，实现语义级别的简历匹配和知识检索。

四、核心技术栈
类别	技术	在项目中的用途
后端主语言	Java, Spring Boot, JavaWeb	构建业务接口、鉴权、会话管理
认证	JWT	无状态用户认证与授权
缓存与记忆	Redis	存储多智能体对话历史、HR筛选上下文、语义缓存
关系型数据库	MySQL	存储用户信息、岗位、简历、最终评估报告
AI 服务语言	Python, FastAPI	构建高性能异步 AI 推理接口
LLM 编排与智能体	LangChain, LangGraph	RAG 流程构建、多智能体协作状态图定义与执行
向量存储与检索	向量数据库 (如 Milvus, Chroma)	简历与岗位的语义匹配、知识库相似度搜索
检索增强生成	RAG	结合知识库与向量检索，让智能体生成有依据的评估
前端 	Vue3 / React	提供 HR 与面试官的操作界面
